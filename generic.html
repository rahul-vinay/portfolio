Software Engineering Co-op
@ DuPont

At DuPont - Spectrum Plastics Group, I got to blend machine learning, automation, and data visualization to make precision manufacturing smarter. From developing predictive models and feedback algorithms in C# and SQLite to optimizing data pipelines, every project was about refining processes and making data-driven decisions more seamless.

I also built real-time visualization tools in Python and C#, turning spatial data, density patterns, and machine feedback into clear, actionable insights. Along the way, I worked on fine-tuning algorithms that helped improve accuracy and streamline adjustments.

Natural Language Processing Intern
@ CAIR, DRDO

At DRDO’s Centre for Artificial Intelligence & Robotics (CAIR), I implemented Snowball, a semi-supervised learning algorithm for relation extraction from unstructured text. Using Python, spaCy, NLTK, and TensorFlow, I developed rhe Snowball model that iteratively extract meaningful relationships between entities with minimal human intervention.

The project involved data preprocessing, Named Entity Recognition (NER), coreference resolution, and bootstrapping techniques, significantly improving the model’s ability to extract relations from text. Hyperparameter tuning was used to refine pattern selection and tuple extraction, improving extraction quality, while 10-fold cross-validation was applied to evaluate model performance across multiple experiments. Running large-scale tests, I fine-tuned parameters to balance precision and recall, ensuring high-quality relation extraction. This experience was a deep dive into text mining, semi-supervised learning, and AI-driven knowledge extraction, tackling real-world NLP challenges and working at the intersection of machine learning and linguistic pattern recognition.
